# Governance

## Roles

- **Maintainers**: review and merge contributions and set project direction (see [CODEOWNERS](.github/CODEOWNERS)).
- **Contributors**: anyone who opens issues or pull requests.

## Decisions

Day-to-day changes are decided by maintainer review on pull requests. Significant or
breaking changes are discussed in an issue or discussion before implementation.

## Becoming a maintainer

Sustained, high-quality contributions may lead to an invitation from the existing maintainers.
