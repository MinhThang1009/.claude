# documentation

Documentation engineering and specialized framework development agents. Covers README, API docs, architecture guides, tutorials, and CHANGELOG.

## Installation

```bash
claude plugin install documentation@dotclaude
```

## Contents

### Agents

- `documentation-engineer` — Writes, updates, and maintains all documentation types; audits existing docs for gaps and outdated content
- `nextjs-developer` — Next.js 14+ App Router specialist covering server components, server actions, rendering strategies (SSG/SSR/ISR/PPR), SEO, and performance
