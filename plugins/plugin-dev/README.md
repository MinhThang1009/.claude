# plugin-dev

Comprehensive toolkit for developing Claude Code plugins including hooks, MCP integration, commands, agents, and skills.

## Installation

```bash
claude plugin install plugin-dev@minhthang-plugins
```

## Contents

### Skills

- `/agent-development` — Guidance on agent structure, system prompts, triggering conditions, and agent development best practices
- `/command-development` — Guidance on slash command structure, YAML frontmatter, dynamic arguments, and user interaction patterns
- `/hook-development` — Guidance for creating PreToolUse/PostToolUse/Stop hooks and other event-driven automation
- `/mcp-integration` — Guidance for integrating Model Context Protocol servers into plugins for external tool and service access
- `/skill-development` — Guidance on skill structure, progressive disclosure, and skill development best practices
