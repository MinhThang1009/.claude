# claude-md-management

Audit, evaluate quality, and improve CLAUDE.md files. Captures session learnings and keeps project memory up to date.

## Installation

```bash
claude plugin install claude-md-management@minhthang-plugins
```

## Contents

### Skills

- `/claude-md-management` — Audit, score, and revise CLAUDE.md files; run at session end to capture learnings

### Commands

- `/claude-md-management` — Audit and improve CLAUDE.md files in the current project
