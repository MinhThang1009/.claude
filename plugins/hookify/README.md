# hookify

Easily create custom hooks to prevent unwanted behaviors by analyzing conversation patterns or from explicit instructions.

## Installation

```bash
claude plugin install hookify@minhthang-plugins
```

## Contents

### Agents

- `conversation-analyzer` — Analyzes conversation transcripts to identify behaviors worth blocking with hooks

### Skills

- `/hookify` — Create Claude Code hooks from conversation analysis or explicit behavior descriptions

### Commands

- `/hookify` — Create hooks to prevent unwanted behaviors from conversation analysis or explicit instructions
- `/configure` — Enable or disable hookify rules interactively
- `/list` — List all configured hookify rules
- `/help` — Get help with the hookify plugin
