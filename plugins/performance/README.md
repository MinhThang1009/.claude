# performance

Performance profiling, optimization, and dependency audit agents. Covers slow queries, bundle size, caching strategy, and dependency hygiene.

## Installation

```bash
claude plugin install performance@dotclaude
```

## Contents

### Agents

- `performance-engineer` — Analyzes and optimizes performance: profiling, benchmarking, database optimization, caching strategy
- `dependency-manager` — Audits dependencies for security vulnerabilities, unused packages, outdated versions, license compliance, and bundle size
