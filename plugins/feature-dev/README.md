# feature-dev

Comprehensive feature development workflow with specialized agents for codebase exploration, architecture design, and quality review.

## Installation

```bash
claude plugin install feature-dev@minhthang-plugins
```

## Contents

### Agents

- `code-architect` — Software architect for system design, architecture decisions, and trade-off evaluation on large features
- `code-explorer` — Deep codebase analysis: execution path tracing, architecture mapping, dependency documentation

### Skills

- `/feature-dev` — Guided feature development — explore codebase, clarify requirements, design architecture, implement, review
- `/explain` — Explain code, algorithms, or architecture from overview down to detail with concrete examples

### Commands

- `/feature-dev` — Guided feature development with codebase understanding and architecture focus
