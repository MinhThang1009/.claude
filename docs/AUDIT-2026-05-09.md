## Decisions deferred

### MIGRATION-* directory rename (plugin branch, audit #11)

**Finding**: A1-architect flagged `MIGRATION-REFERENCES/` và `MIGRATION-RULES/` directory naming UPPERCASE-DIR-PREFIX không match GitHub/Anthropic/Unix convention nào.

**Recommendation gốc**: move sang `docs/migration/`.

**Decision**: DEFER cho follow-up milestone.

**Rationale**:
- MIGRATION-* root layout là intentional install ergonomics — user copy thẳng từ root vào `~/.claude/`.
- README.md install commands (3 OS variants: bash/PowerShell/CMD) reference paths trực tiếp.
- Rename impact spans 7+ files: README, SECURITY.md, pull_request_template.md, plugin-experiment-results.md, MIGRATION-RULES/communication.md cross-ref.
- Tag `dotclaude-v0.1.0-experimental` đã re-pointed — đổi structure sau sẽ cần re-tag thêm 1 lần nữa.

### CLAUDE.md absent on plugin branch (audit #5)

**Finding**: Plugin branch không có `CLAUDE.md` root (vs main có).

**Decision**: ACCEPT as intentional design.

**Rationale**: Plugin branch distribute qua `claude-code-plugin-manifest.json` — user copy `MIGRATION-CLAUDE.md` qua `~/.claude/CLAUDE.md` thủ công sau install. Không cần root CLAUDE.md trên plugin branch vì plugin format là distribution package, không phải user-config repo.

### kcov code coverage cho hook tests (audit #1)

**Decision**: DEFER cho follow-up milestone.

**Rationale**: Bash coverage notoriously imprecise (kcov tính line theo `case` statement riêng → 60-70% reported even khi run đầy đủ). Modification of `hook-tests` job risky cho 119 tests đã passing. Ưu tiên high-signal automation (CodeQL/commitlint/cspell/gitleaks) trước.

### Branch protection rules (audit #1, B1 INFO-3)

**Decision**: DEFER — config qua GitHub Settings UI (require PR + status checks + signed commits), không file commit. Maintainer enable khi sẵn sàng.
